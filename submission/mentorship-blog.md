# LFX Linux Kernel Mentorship Blog

## From Embedded Linux to Kernel Contributor: My Linux Kernel Mentorship Journey

This is the companion blog for my **LFX Linux Kernel Mentorship — Spring 2026**. The full, reader-friendly version of the journey is being developed as a GitHub Pages site:

**Blog:** https://sanjay-embedded.github.io/LFX-Linux-kernel-Spring-2026/

The blog highlights the journey from my background in Embedded Linux, BSP and product development, through hands-on upstream Linux kernel development in the IIO subsystem, toward continuing as an independent Linux kernel contributor.

The detailed mentorship repository remains the technical record of the work, including milestones, growth notes, patch series, review experience and contribution evidence.

### Mentorship snapshot

- **Program:** LFX Linux Kernel Mentorship — Spring 2026
- **Duration:** 1 March 2026 – 31 August 2026
- **Organization:** Linux Foundation
- **Mentors:** Shuah Khan & Brigham Campbell
- **Primary subsystem:** Industrial I/O (IIO)
- **Mainline:** 20+ accepted commits
- **linux-next:** 25+ additional commits
- **Focus:** Driver modernization, resource management, error handling, lifecycle improvements and upstream development workflow

### Journey

```text
Before mentorship

Embedded Linux / BSP / product development
                ↓
Mentorship

Upstream Linux kernel development
                ↓
After mentorship

Independent kernel contributor
```

The central theme of the blog is not simply the number of patches accepted. It is how the mentorship changed my approach to kernel development: understanding subsystem expectations, structuring reviewable patch series, responding to maintainer and reviewer feedback, following linux-next, and thinking more deeply about resource ownership, lifecycle and maintainability.

The GitHub Pages article will be refined iteratively before the final mentorship submission.

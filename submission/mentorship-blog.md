# LFX Linux Kernel Mentorship Blog

## From Embedded Linux to Kernel Contributor: My Linux Kernel Mentorship Journey

This is the companion blog for my **LFX Linux Kernel Mentorship — Spring 2026**. The full, reader-friendly version of the journey is being developed as a GitHub Pages site:

**Blog:** https://sanjay-embedded.github.io/LFX-Linux-kernel-Spring-2026/

The blog focuses on the transition from my Embedded Linux, BSP and product-development background to deeper and sustained participation in **upstream Linux kernel development**, with the Industrial I/O (IIO) subsystem as the primary area of work.

### The journey

```text
Before mentorship

Embedded Linux / BSP / product development
                ↓
Mentorship

Upstream Linux kernel development
                ↓
After mentorship

Independent Linux kernel contributor
```

A central lesson from the mentorship was that an upstream patch is not only about fixing code. It also needs to be easy to review, maintain and integrate. The work also reinforced the value of modernizing drivers according to current kernel practices as preventive maintenance, reducing unnecessary complexity and potential future failure paths rather than waiting for a specific bug to appear.

The detailed mentorship repository remains the technical record of the work, including milestones, growth notes, patch series, review experience and contribution evidence.

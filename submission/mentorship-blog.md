# LFX Linux Kernel Mentorship Blog

## From Embedded Linux to Kernel Contributor: My Linux Kernel Mentorship Journey

**LFX Linux Kernel Mentorship — Spring 2026**  
**Primary subsystem:** Industrial I/O (IIO)

**Blog:** https://sanjay-embedded.github.io/LFX-Linux-kernel-Spring-2026/

This blog captures my transition from an Embedded Linux, BSP and product-development background to deeper participation in the **upstream Linux kernel community** through the IIO subsystem.

### Journey

```text
Embedded Linux / BSP / Product Development
                    ↓
        LFX Linux Kernel Mentorship
                    ↓
     Independent Linux Kernel Contributor
```

The mentorship focused on driver modernization and preventive maintenance, resource ownership and lifecycle, review-driven patch development, and the upstream workflow from mailing-list submission through linux-next and mainline.

A key lesson was that a good upstream patch is not only about fixing code; it must also be easy to review, maintain, integrate and bisect. My most memorable review guidance was:

> **“The rule of thumb is one logical change per patch.”**

The full technical evidence and contribution history are maintained in this repository. A reusable guide for future contributors is also available:
